# Wealth-X

> Wealth-X (an Altrata company) provides curated wealth intelligence on ultra-high-net-worth (UHNW) and very-high-net-worth (VHNW) individuals and their privately held companies. The legacy Wealth-X Connect REST API delivers dossiers, advanced prospect search and bulk/incremental sync. Altrata's own developer docs state that Wealth-X customers are migrating to the unified Altrata GraphQL platform, which is where new wealth data now ships.

Generated by the API Evangelist enrichment pipeline from this repository's artifacts. Wealth-X also publishes its own llms.txt at https://wealthx.com/llms.txt — that document is the Altrata corporate index and is saved verbatim beside this file as `wealth-x-llms-published.txt`.

## APIs (legacy — Wealth-X Connect)

- [Wealth-X Connect API](https://developers.wealthx.com/api/main.html): REST over https://connect.wealthx.com/rest/v1 for dossier retrieval, advanced search, and reference data. Auth is three request headers sent together: username, password, apikey. Status: legacy, with a documented migration path to Altrata.

## APIs (successor — Altrata platform, GraphQL)

- [Profile API](https://docs.altrata.com/profile-api): https://profile.altrata.com/v1/graphql/ — person and organization search and enrichment, including net worth, wealth assets, charitable and political donations. Rate limit 2/s.
- [Relationship API](https://docs.altrata.com/relationship-api): https://relationships.altrata.com/v1/graphql/ — paths from the current user to a target person or organization (1st/2nd degree), and full person networks. Rate limit 100/s, burst 50.
- [Events API](https://docs.altrata.com/events-api): https://events.altrata.com/v1/graphql — leadership and organizational announcements by person or organization, newest first. Polled, not pushed. Rate limit 2/s.
- [Matching API](https://docs.altrata.com/api): https://matching.altrata.com/v1/graphql — asynchronous bulk match of a customer dataset against Altrata. Submit, poll status, page results. 6MB max per POST. Rate limit 100/s, burst 50. Accepts wxPersonId (the Wealth-X person identifier) as a match input.

## Agent surface

- [Altrata MCP server](https://mcp.altrata.com/mcp): a live remote MCP endpoint operated by Wealth-X's parent Altrata. OAuth-protected (authorization_code + PKCE, Amazon Cognito, scopes `openid email`). Anonymous `tools/list` returns HTTP 401, so the tool list requires an authenticated introspection pass. Rate limit 500 requests / 60s.
- No A2A agent card is published on any Wealth-X or Altrata host.

## Specs

- [OpenAPI (generated)](openapi/wealth-x-connect-openapi.yml): OpenAPI 3.0.3 generated from the published Wealth-X API Samples Postman collection, split by tag into dossiers / search / reference.
- No OpenAPI is published by the provider. The Altrata GraphQL schemas are auth-gated; no SDL could be captured.

## Legacy operations (Wealth-X Connect)

- getDossier — GET /dossiers/{dossierId}: single dossier, shaped by view (stub/selective) and fields.
- getAllDossiers — GET /alldossiers: bulk download by IDs, index range, net-worth band, or last-modified window.
- searchDossiersAdvanced — POST /dossiers/search/advanced: search by name, company, geography, net worth, industry, position, interests, education, philanthropy, relationships.
- getLastDossierId — GET /lastdossierid: high-water-mark ID for incremental sync.
- listCountries — GET /countries.
- listStates — GET /countries/{countryId}/states.
- listIndustryTypes — GET /industrytypes.
- listPositions — GET /positions.

## Conventions an agent must know

- Pagination on the Altrata platform is cursor-based: `pageInfo{after,before,first,last}` in, `pageInfoResponse{totalCount, pageInfo{hasNextPage,hasPreviousPage,startCursor,endCursor}}` out. `last` is only valid with `before`.
- Named GraphQL fragment spreads are NOT supported, including on nested fields. Use inline fragments only.
- Partial responses are normal: requesting a field outside the subscription entitlement returns an error block with errorType `unauthorized` while the rest of the payload stays valid and consumable.
- Deprecation is signalled in-band as errorType `deprecated`, never as an RFC 8594 Sunset header. Deprecated fields are removed in later releases.
- Any other errorType means the response payload must be discarded.
- No idempotency key exists on any surface.
- 429 is returned both for per-second rate exhaustion and for daily quota exhaustion. Retry with exponential backoff and jitter.

## Access

- No self-serve signup, no free tier, no public sandbox. Credentials are issued by a client success representative during subscription setup (clientsuccess@altrata.com).
- No prices are published. wealthx.com/pricing and altrata.com/pricing both return 404.
- No status page. status.wealthx.com and status.altrata.com do not resolve.
- No published SLA.
