# Wealth-X

> Wealth-X (an Altrata company) provides curated wealth intelligence on ultra-high-net-worth (UHNW) and very-high-net-worth (VHNW) individuals and their privately held companies. The Wealth-X Connect API delivers this data — dossiers, advanced prospect search, and bulk/incremental sync — directly into a subscriber's CRM or data platform.

## APIs

- [Wealth-X Connect API](https://developers.wealthx.com/api/main.html): REST API over https://connect.wealthx.com/rest/v1 for dossier retrieval, advanced search, and reference data. Auth is three headers: username, password, apikey.

## Specs

- [OpenAPI (generated)](openapi/wealth-x-connect-openapi.yml): OpenAPI 3.0.3 generated from the published Wealth-X API Samples Postman collection.

## Operations

- getDossier — GET /dossiers/{dossierId}: single dossier, shaped by view (stub/selective) and fields.
- getAllDossiers — GET /alldossiers: bulk download by IDs, index range, net-worth band, or last-modified window.
- searchDossiersAdvanced — POST /dossiers/search/advanced: search by name, company, geography, net worth, industry, position, interests, education, philanthropy, relationships.
- getLastDossierId — GET /lastdossierid: high-water-mark ID for incremental sync.
- listCountries — GET /countries.
- listStates — GET /countries/{countryId}/states.
- listIndustryTypes — GET /industrytypes.
- listPositions — GET /positions.
